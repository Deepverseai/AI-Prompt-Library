# Learning Prompt

## Prompt

Explain any technical topic to me in simple language, using examples and step-by-step explanations.

## Purpose

Useful for learning difficult technical concepts.

## Coding Prompt

Explain this code to me step-by-step in simple language.

For any code I provide:
1. Explain what it does.
2. Explain each important part.
3. Point out possible errors.
4. Suggest improvements.
